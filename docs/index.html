07faq
Why does my scroll do nothing?
macOS silently drops wheel events posted to the HID event tap — the route most tutorials use. This server posts pixel-unit events to the session tap via Apple's bundled Python (pyobjc). Documented in code, proven in tests.
Does it steal focus to observe an app?
activate:false captures and reads a background window without raising it. Activation is opt-in per call; launching apps always is.
How does the agent know its click worked?
The next observation carries diff markers keyed by tree position: which elements appeared, which changed, which vanished. Selection results are verified against element content, not trusted.
macOS only?
Yes — the driving stack is System Events, CGWindowList, screencapture and cliclick. That's also why the whole thing fits in one auditable binary.
Zero dependencies — even for scrolling?
Everything except synthetic scroll, which shells to Apple's bundled /usr/bin/python3 (pyobjc ships with the Xcode CLT). No pip anywhere.
